# LPAUW0389\_0389\_35727 - Heks zendt vrouwen elke dag de plaag

Een sage (mondeling), 1969

### Hoofdtekst

### Beschrijving

Op ’t Kruis in Moorsel stierven in een korte periode verschillende jonge vrouwen. Een vrouw die iedere avond op hetzelfde tijdstip een soort aanval kreeg, ging naar de witte paters van Gent, die haar de raad gaven om alles wat ze ooit van iemand had geleend, terug te brengen. Toen de vrouw dat had gedaan, werd alles weer normaal.
